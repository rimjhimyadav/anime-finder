# Anime Finder

Anime search app made with HTML, CSS and JavaScript. Uses the free [AniList API](https://docs.anilist.co) (no API key needed).

![demo](demo/demo.gif)

## Features

- big banner with the #1 trending anime
- browse Trending, Top Rated, Popular and Upcoming anime
- search any anime by name
- filter by genre
- load more results
- click a card to see full details (synopsis, studio, episodes, trailer and more)
- My List with Watching / Plan to Watch / Completed status (saved in localStorage)
- works on mobile

## How to run

Just open `index.html` in the browser.
